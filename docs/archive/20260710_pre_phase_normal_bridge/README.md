# Pre-Phase-Normal-Bridge Archive

Archived on 2026-07-10 when the active Stage-2 method changed to the
endpoint-exact asynchronous phase-normal bridge.

These files remain useful as experiment provenance, negative results, and
historical design context. They are not active instructions and must not be
used to infer the current model contract.

## Why These Files Moved

- `free-flow`, generic boundary residual, and warp-only plans were superseded
  by the identifiable phase plus normal-residual parameterization.
- ESM/REPA plans are representation experiments rather than the central method.
- Stage-1 teacher-posterior plans belong to the future no-Oracle deployment
  track, not the current endpoint-conditioned conference paper.
- The old proposal described a Holo decoder and unconstrained ODE/CFM route
  that no longer matches the implemented system.
- Old runbooks and status notes referenced obsolete jobs, cache contracts, and
  selection criteria.
